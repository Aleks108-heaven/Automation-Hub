# TopicCard

A clickable card that introduces one learning module on the Hub home and track pages.

- **Consumer provides:** an `<a class="ah-card">` containing `ah-card__eyebrow` (module number, mono), `ah-card__title` (h3), `ah-card__body` (one or two sentences) and optionally `ah-card__foot` with up to two badges (reading time, status).
- Lay out in a grid with `space-4`–`space-6` gaps; minimum card width 240px.
- Cards are flat on a `line` hairline; `shadow-raised` appears only on hover.
- Don't: add coloured side stripes, icons or images; write more than two sentences of body.
